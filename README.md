---

## Cómo publicar gratis en Netlify

1. Ve a [netlify.com](https://netlify.com) y crea una cuenta gratuita
2. En el panel, busca la sección **"Deploy manually"**
3. Arrastra el archivo `index.html` a la zona de carga
4. Netlify genera una URL pública automáticamente (ej: `moonye-abc123.netlify.app`)
5. Para personalizar la URL: **Site settings → Site name → moonye** → quedará `moonye.netlify.app`

## Personalización

Abre `index.html` con cualquier editor de texto (Notepad, VS Code, etc.) y reemplaza:

| Texto a buscar | Reemplazar con |
|---|---|
| `contacto@moonye.com` | Tu email real |
| `+57 300 000 0000` | Tu número de WhatsApp |
| `Bogotá, Colombia` | Tu ciudad si es diferente |
| `+50 Proyectos completados` | Tu número real de proyectos |
| `+5 Años de experiencia` | Tus años reales de experiencia |
